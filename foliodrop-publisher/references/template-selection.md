# Template Selection

Select one template category, copy the asset, and adapt it. Do not load every template unless the user asks to compare styles.

## Categories

### Deck

Use `assets/templates/deck/product-demo.html`.

Best for:

- Pitch decks
- Product demos
- Internal proposals
- Course mini-lessons
- Visual narratives that need slide-by-slide pacing

Output should stay 16:9 and support simple click or keyboard progression when adapted.

### Resume

Use `assets/templates/resume/operator-resume.html`.

Best for:

- Job applications
- Founder/operator profiles
- Designer or developer intro pages
- Printable profile pages

Prioritize scannability, proof, metrics, contact methods, and print-friendly layout.

### Email Campaign

Use `assets/templates/email-campaign/product-launch.html`.

Best for:

- Product launch email previews
- Newsletter sponsorship mockups
- Lifecycle campaign drafts
- Founder update emails

Keep it email-like but publish as an HTML preview page. Do not send email from this skill.

### One-Page

Use `assets/templates/onepage/micro-saas-launch.html`.

Best for:

- Product launches
- Waitlists
- Service offers
- Tool explainers

Lead with the literal offer or product name, then proof, workflow, pricing, and call to action.

### Portfolio

Use `assets/templates/portfolio/case-study.html`.

Best for:

- Design case studies
- Client previews
- Creative work galleries
- Project retrospectives

Show context, constraints, process, outcome, and artifact previews. Keep captions specific.

## Selection Rule

If the user asks for a format, use that format. If the user only describes an outcome, choose the format that minimizes user effort:

- "share this idea" -> one-page
- "present this" -> deck
- "apply for this" -> resume
- "launch announcement" -> email campaign or one-page
- "show my work" -> portfolio
