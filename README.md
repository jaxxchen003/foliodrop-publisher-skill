# FolioDrop Publisher Skill

[中文](#中文) | [English](#english)

## 中文

FolioDrop Publisher 是一个面向 Codex / AI agent 的可分发 skill。它把一个想法或已有 HTML 作品变成完整的单文件 HTML，并通过 FolioDrop 发布成真实可分享链接。

它的定位不是“通用网站部署工具”，而是：

> 让 AI 直接把你的想法变成一个漂亮的公开链接。

### 适合场景

- 发布 ChatGPT 或其他 agent 生成的 HTML 页面
- 生成并发布 16:9 HTML 演示稿 / pitch deck
- 生成可打印、可分享的 HTML 简历
- 生成产品发布邮件预览
- 生成 micro-SaaS / 产品 one-page
- 生成设计作品集 case study
- 检查 HTML 是否符合 FolioDrop 的单文件发布规则

### FolioDrop 发布路径

该 skill 会优先使用 agent host 已连接的 FolioDrop 工具：

- Remote MCP: `https://foliodrop.app/mcp`
- Public MCP descriptor: `https://foliodrop.app/api/ai/mcp-config.json`
- OpenAPI: `https://foliodrop.app/api/ai/openapi.json`

如果当前 agent 没有连接发布工具，skill 会引导用户打开：

- AI 连接设置：`https://foliodrop.app/ai`
- 手动发布页面：`https://foliodrop.app/publish`

### HTML 边界

FolioDrop 发布的是一个完整 HTML work，不是 ZIP、Next.js/Vite 项目、React 源码目录或多页网站。

发布前 HTML 应满足：

- 包含 `<!doctype html>`、`<html>`、`<head>`、`<body>`
- CSS 内联到 `<style>`
- JavaScript 内联到 `<script>`，且只在需要时使用
- 外部图片、字体、媒体资源使用公开 `https://` URL
- 不包含私钥、token、密码或本地文件路径

### 授权与安全

FolioDrop AI token 应被当作密码处理。不要把 token 写入 HTML、README、日志、issue、截图或最终回复中。

如果要大范围开源传播，建议先补充明确 license。当前仓库未附带开源 license。

### FolioDrop publishing paths

The skill prefers a FolioDrop tool already connected in the agent host:

- Remote MCP: `https://foliodrop.app/mcp`
- Public MCP descriptor: `https://foliodrop.app/api/ai/mcp-config.json`
- OpenAPI: `https://foliodrop.app/api/ai/openapi.json`

If no publishing tool is connected, the skill guides the user to:

- AI connection setup: `https://foliodrop.app/ai`
- Manual publishing: `https://foliodrop.app/publish`

### HTML boundary

FolioDrop publishes one complete HTML work, not ZIP files, Next.js/Vite projects, React source directories, or multi-page websites.

Before publishing, HTML should:

- Include `<!doctype html>`, `<html>`, `<head>`, and `<body>`
- Inline CSS in `<style>`
- Inline JavaScript in `<script>` only when needed
- Use public `https://` URLs for external images, fonts, and media
- Avoid private keys, tokens, passwords, or local file paths

Treat FolioDrop AI tokens like passwords. Do not place tokens in HTML, README files, logs, issues, screenshots, or final agent responses.

For broad open-source distribution, add an explicit license first. This repository does not currently include an open-source license.
